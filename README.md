# Daniel's Voice

Сайт с подкастом, медитациями и аудиозаписями.

## Как добавить новый выпуск подкаста

### Шаг 1. Получить iframe-код из Mave

После публикации выпуска на Mave, скопировать код плеера. Он выглядит так:

```html
<iframe src="https://player.mave.digital?podcast=rebel-psychology&episode=N&color=rgb(95,128,245)&mute=1&date=1&download=1" style="width: 100%" height="235" scrolling="no" frameborder="no"></iframe>
```

Где `N` — номер эпизода (1 = трейлер, 2 = пилот, 3 = третий выпуск и т.д.).

### Шаг 2. Придумать slug

Slug — это короткое латинское имя для URL. Примеры:

| Название выпуска | Slug |
|---|---|
| Трейлер | `trailer` |
| Пилот | `pilot` |
| Руководство пользователя биологической нейросети | `bio-neural-guide` |

Правила: только латиница, цифры и дефисы. Без пробелов и спецсимволов.

### Шаг 3. Добавить данные в `data/audio.php`

Открыть файл `data/audio.php` и добавить новый блок в массив `$AUDIO_DATA`.

Вставлять **после последнего эпизода подкаста** (после блока `'podcast/...'`), но **перед** блоком `'thoughts/...'`.

```php
'podcast/SLUG' => [
    'id' => 'podcast/SLUG',
    'title' => 'Название выпуска',
    'description' => 'Описание выпуска.',
    'category' => 'podcast',
    'duration' => 'MM:SS',
    'audioFile' => '',
    'publishDate' => 'ГГГГ-ММ-ДД',
    'platforms' => [],
    'embedPlayer' => '<iframe src="https://player.mave.digital?podcast=rebel-psychology&episode=N&color=rgb(95,128,245)&mute=1&date=1&download=1" style="width: 100%" height="235" scrolling="no" frameborder="no"></iframe>',
],
```

Что заменить:

- `SLUG` — slug из шага 2 (в двух местах: ключ массива и поле `id`)
- `Название выпуска` — заголовок
- `Описание выпуска` — краткое описание
- `MM:SS` — длительность (например `18:49`)
- `ГГГГ-ММ-ДД` — дата публикации (например `2026-02-16`)
- `episode=N` — номер эпизода в iframe

### Шаг 4. Создать страницу эпизода

1. Создать папку `podcast/SLUG/`
2. Скопировать в неё файл `podcast/bio-neural-guide/index.php`
3. Открыть скопированный файл и поменять **две вещи**:

**Строка 3** — комментарий (необязательно, для удобства):
```php
 * Эпизод: Название выпуска
```

**Строка 10** — ID эпизода (обязательно):
```php
$audioId = 'podcast/SLUG';
```

Всё остальное подтягивается автоматически из данных в `audio.php`.

### Шаг 5. Проверить

- `/podcast/` — новый выпуск должен появиться первым в списке
- `/podcast/SLUG/` — страница эпизода с mave-плеером

Блок 1. Литературный и контентный анализ
Описания подкастов и их ценность для слушателя
Главная проблема — описания написаны для автора, а не для слушателя. Возьмём конкретные примеры:
«Пилот»: «Пилотная серия подкаста. Поговорим о сложном мире, в котором мы живем. Поговорим об автопилоте, на котором мы пытаемся решить наши проблемы. Рассмотрим альтернативу для автопилота.» — это не описание, это оглавление. Слушатель не понимает, что именно он получит и зачем тратить 21 минуту.
«Руководство пользователя биологической нейросети»: «Как не поглупеть от нейросетей? Что делать, чтобы эффективно настроить свою биологическую нейросеть? Базовые правила ухода за своей нервной тканью...» — чуть лучше, потому что есть вопросы-крючки, но обрывается на полуслове («...и много другое вы узнаете в этом руководстве» — это журналистика 2005 года).
«Короткая психологическая практика»: «Моя первая записанная практика. Не совсем техника осознанности, больше практическая демонстрация. Выложил её на сайт, чтобы точка 'С чего я начал' была доступна в интернете» — это вообще не описание для слушателя, это авторский дневник. Человек, который зашёл впервые, не понимает, зачем ему это слушать.
«Друзья, философия, коньяк — не помогло. Что теперь?»: Описание: «Искал причины, по которым плеяда психологов вообще существует» — одна строка, содержательно пустая. А заголовок при этом один из лучших на сайте.
Вывод: Ни одно описание не даёт ответа на вопрос «что изменится в моей жизни, если я это послушаю?» Все описания фиксируют тему, а не трансформацию.
Узнаваемый голос автора
Голос есть, и это главный актив проекта — но он проявляется неравномерно. В хорошие моменты он звучит чётко:

«Без "успешного успеха" и девчачьего "нужно просто себя полюбить"» — честно, конкретно, с позицией
«Коротко. По делу. Иногда неудобно» (подзаголовок «Нетленки») — отличный слоган, точный
Страница «О проекте» написана живо: раздражение на приложения с подписками передаётся, есть личное отношение
Но в описаниях эпизодов этот голос исчезает и заменяется нейтральным пересказом. Разрыв очень заметен: главная говорит с характером, страницы эпизодов — безликие.

Это нормально для MVP, но 60% — это потери аудитории на первом касании.

Стилевая согласованность
Три разных голоса существуют на одном сайте:

Главная страница — резкий, позиционирующий, с характером
Страница «О проекте» — разговорный, личный, живой
Страницы эпизодов — технический пересказ без автора
Кроме того, есть терминологическая непоследовательность. На главной написано «медитации и подкасты», на основном сайте daniel-ivanov.ru автор позиционируется как «ACT-психотерапевт», а на подкаст-сайте специализация ACT нигде не упоминается. Слушатель, пришедший с подкаста, не знает, с кем именно работает — и почему этому человеку стоит доверять.


Что работает, что слабо
Работает:

Нишевое позиционирование «психология для айтишников» — конкретно и проверяемо
IT-бэкграунд автора как доверительный сигнал (TypeScript, 6 лет, продуктовые компании)
Тезис «без эзотерики» — чёткий антагонист, аудитория понимает, чего не будет
Заголовок «Нетленки» с подзаголовком — лучший пример голоса на сайте
Честная позиция «почему всё бесплатно» — редкость в нише
Слабо и шаблонно:
«Только доказательная прикладная психология, без успешного успеха» — встречается буквально дословно в трёх разных местах (главная, категория, страница подкаста). Это мантра, а не аргумент
Описания эпизодов написаны в формате «о чём поговорим», а не «что вы получите»
Фраза «много другое вы узнаете» — это худший приём копирайтинга
«Как появился этот сайт» — заголовок страницы «О проекте»: слабый, не продающий интерес к странице


Блок 2. Бизнес-анализ
Первый экран — понятно ли, зачем и кому
«Для тех, кто устал жить на автопилоте» — хороший заголовок, но он слишком широкий. Устать от автопилота могут все. Нишевое позиционирование «для айтишников» появляется только в подзаголовке, а первая строчка принадлежит всему человечеству.
Кнопка «Хочу попробовать» ведёт в якорь #audio-catalog — хороший выбор, прямое действие. Кнопка «Как это работает?» ведёт на /about/ — страницу с заголовком «Как появился этот сайт». Это несоответствие: пользователь нажимает «как это работает» и читает историю создания сайта вместо объяснения механики контента.
Конверсионные элементы
На сайте есть:

Ссылка «Посетить личный сайт» (блок «Об авторе» + подвал)
«Запись на консультации» в подвале
Ссылки на Telegram-каналы, YouTube, ВКонтакте
Чего нет:
Никакого призыва подписаться на уведомления о новых эпизодах на самом сайте
Никакого внятного CTA на страницах отдельных эпизодов — только шаблонный «Посетить личный сайт» после блока «Об авторе»
Email-подписки нет намеренно (автор объясняет это в «О проекте») — это честная позиция, но тогда нет вообще никакого механизма удержания, кроме Telegram
Кнопка «Подписаться» в плеере Mave ведёт в интерфейс Mave — это не подписка на сайт, а технический функционал. Слушатель, который хочет остаться в контакте, должен сам догадаться пойти в Telegram.


Связь с daniel-ivanov.ru — воронка или параллельные миры
Сейчас — параллельные миры. Точки связи:

Ссылка «Посетить личный сайт» (пассивная, в описании автора)
«Запись на консультации» в подвале (ссылка на /contacts основного сайта)
В описаниях эпизодов на Mave вставлены ссылки на основной сайт вручную
Что не работает:
Основной сайт daniel-ivanov.ru не ссылается на подкаст вообще (я проверил главную страницу)
Аудитория основного сайта не знает о подкасте
Подкаст-сайт позиционируется только на айтишников, основной сайт — на более широкую аудиторию (там есть «нарушения пищевого поведения», «расставания» — это не IT-тематика). Это либо стратегическое разделение, либо несогласованность позиционирования
Воронка должна работать так: подкаст → доверие → запись на консультацию. Сейчас эта цепочка существует технически, но не оформлена как путь. Человек сам должен догадаться, что перейти по ссылке в подвале — это следующий шаг.


Аналоги в русскоязычном пространстве
Три наиболее близких проекта (по информации до начала 2025 года, актуальность могла измениться):
«Психология на диване» — один из самых известных психологических подкастов в РФ, широкая аудитория, нет ниширования, академический тон. Слабость — именно то, от чего отстраивается Даниил: нет конкретной аудитории.
«Это норма» (Яндекс Музыка) — форматный подкаст с гостями, популярный у широкой аудитории, лёгкий тон. Нет IT-специфики, нет практических инструментов.
«Ресурс» и похожие проекты «психолог+медитации» — обычно без чёткого ниширования, смешение mindfulness и поп-психологии.
Чем этот проект отличается или может отличаться: Ниширование на IT — единственная настолько жёсткая специализация в русскоязычном сегменте. IT-бэкграунд автора как credential — в нише психологических подкастов это редкость. Формат «три жанра в одном месте» (медитации + разговорный подкаст + блог вслух) — это может быть силой (экосистема) или слабостью (размытость), в зависимости от того, как это будет позиционироваться.
Бизнес-роль подкаста и её реализация
Потенциальные роли: личный бренд + доверие → трафик на основной сайт → запись на терапию.
Сейчас реализовано примерно на 20–30%:

Личный бренд строится (голос есть, позиционирование есть), но не конвертируется
Трафик между сайтами не организован системно
Монетизация через консультации — единственный путь, но он спрятан в подвале
Нет никакого сигнала «сколько людей уже слушают» — социального доказательства нет вообще


Блок 3. Дизайн и UX
Первое впечатление
Сайт говорит «надёжно и профессионально, но без претензий». Светлый фон, тёмные заголовки, минимум декора — это работает в пользу позиционирования «без эзотерики». Никаких фиолетовых градиентов, хрустальных шаров, звёзд. Это плюс.
Но сайт также говорит «сделано на шаблоне» — и это заметно примерно через 10 секунд. Одинаковые белые карточки с тенями, стандартный шрифт, отсутствие каких-либо дизайнерских решений, которые бы отражали личность автора. Дизайн «Нетленки» (граффити на кирпиче) и дизайн «Внутри тишины» (акварель со стулом у воды) — два разных визуальных языка в одном проекте. Это MVP-решение, которое будет нужно унифицировать.
Соответствие позиционированию
Позиционирование «доказательная психология для технарей» в дизайне проявляется слабо. Что ожидаешь увидеть на сайте для программистов: структуру, чёткость, возможно немного «технический» визуальный язык (не обязательно dark theme, но что-то, что резонирует с аудиторией). Что есть: стандартный lifestyle-блог с белыми карточками.
Обложка подкаста «Психопогромизм» (PSYCHOLOGY FOR IT PODCAST с рисованными кляксами) и сайт — два совершенно разных стилистических решения. Обложка живая, с характером. Сайт — спокойный и корпоративный.
Удобство поиска и прослушивания
Плеер Mave встроен прямо на страницу — это хорошо, можно слушать без перехода. Но:

На главной странице нет ни одного встроенного плеера — только текстовые карточки
Навигация по категориям (Внутри тишины / Нетленка / Психопогромизм) логична, но слово «Нетленка» не говорит новому пользователю ровно ничего о содержании
Нет никакой фильтрации или поиска (при 5 эпизодах — ещё не критично, но стоит заложить архитектуру)
На странице категории «Нетленка» записи помечены тегом «Подкаст» — это технический артефакт, не ошибка содержания


Мобильная версия
Браузер в тестовой среде не позволил полноценно протестировать мобильную версию (окно не масштабируется), однако по структуре разметки (кнопка «Меню» ref_8 скрыта в desktop-версии, а навигационные ссылки ref_9–12 дублируются — это паттерн адаптивного меню) можно предположить, что мобильная адаптация есть. Тем не менее рекомендую проверить на реальном устройстве критичный кейс: карточки эпизодов в мобиле — не обрезаются ли описания так, что теряется смысл.
Что выглядит как MVP-заглушка

Описание «Короткой психологической практики» — «Выложил, чтобы точка 'С чего я начал' была доступна» — это авторская нотатка, не контент для аудитории
Дата публикации «Короткой практики» — 15 января 2026, но в плеере Mave — 17 февраля 2026. Рассинхрон дат создаёт впечатление небрежности
«Daniel's Voice» в шапке — неработающая ссылка на главную (функционально работает, но визуально — просто текст, не логотип)
Блок «О сайте» в нижней части /about/ — «Все аудиофайлы содержат корректные метаданные и доступны для скачивания в формате MP3» — это техническая документация, которую никто не читает
Подвал слишком нагружен: одновременно есть «Telegram (личный)» и «Telegram канал» без объяснения разницы — что из этого подписка, а что личный контакт?


Итог: 3 критических проблемы и 3 точки роста
🔴 Три критических проблемы
1. Описания эпизодов не продают прослушивание
Это самая острая проблема. Человек видит карточку — и у него нет ни одной причины нажать «Прослушать», кроме заголовка. Описания нужно переписать по принципу «боль → что произойдёт за 20 минут → первый шаг». Это задача на 2–3 часа работы и даст немедленный эффект на конверсию в прослушивание.
2. Подкаст-сайт не конвертирует в запись на консультацию
Нет маршрута. «Запись на консультации» спрятана в подвале среди ВКонтакте и YouTube. На страницах эпизодов нет ни одного CTA, который переводил бы тёплого слушателя на следующий шаг. Нужна хотя бы одна точка: плашка после плеера — «Работаем индивидуально: подберём подход под ваш запрос» + кнопка на /contacts.
3. Архитектура контента создаёт путаницу
Три раздела (Внутри тишины / Нетленка / Психопогромизм) — это фактически три разных продукта с разным форматом, разной аудиторией и разными обложками. Новый пользователь не понимает, с чего начать и чем они отличаются. Нужен либо онбординг («если вы здесь впервые — начните с…»), либо упрощение архитектуры до одного–двух разделов.
🟢 Три точки роста
1. IT-ниша — это реальное конкурентное преимущество, которое сейчас используется вполовину
Нигде на сайте нет конкретных IT-ситуаций в описаниях: импостер-синдром, code review в 23:00, выгорание от Agile, тревога из-за layoffs. Эти слова есть на основном сайте, но не в подкасте. Если описания эпизодов будут говорить именно об этом — сайт начнёт работать как SEO-актив для очень конкретных запросов.
2. «Нетленка» — самый недооценённый формат
Заголовок «Друзья, философия, коньяк — не помогло. Что теперь?» — это лучший материал на сайте. Короткий разговорный формат (8 минут), живой голос, провокационный тезис.
