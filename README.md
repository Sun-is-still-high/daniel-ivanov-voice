# Daniel's Voice

Сайт с подкастом, медитациями и аудиозаписями.

## Как теперь устроены данные

Источник данных один: RSS-ленты Mave.

- Главная страница и страницы рубрик читают выпуски напрямую из RSS.
- Отдельные страницы выпусков тоже строятся из RSS.
- Ручного массива аудиозаписей в проекте больше нет.

Основная логика находится в:

- `includes/config.php` — конфигурация сайта и рубрик
- `includes/functions.php` — общие функции рендера
- `includes/rss.php` — загрузка, кэширование и поиск выпусков по RSS
- `episode.php` — универсальная страница отдельного выпуска

## Как добавить новый выпуск

Ничего добавлять в код не нужно.

Достаточно:

1. Опубликовать выпуск в Mave.
2. Убедиться, что он появился в RSS соответствующей рубрики.
3. При следующем обновлении кэша выпуск автоматически появится:
   - на главной,
   - в списке своей рубрики,
   - на отдельной странице выпуска,
   - в sitemap эпизодов.

## URL выпусков

Страницы выпусков формируются автоматически по RSS и доступны по шаблону:

- `/podcast/{slug}/`
- `/inside-the-silence/{slug}/`
- `/netlenka/{slug}/`

Slug строится автоматически из заголовка выпуска. Если slug не удается построить из заголовка, используется идентификатор из ссылки Mave.

## Кэш RSS

RSS-фиды кэшируются в папке `cache/`.

- Кэш используется для ускорения загрузки страниц.
- Если нужно срочно подтянуть свежий выпуск, можно удалить соответствующий файл `cache/rss_*.xml`.
